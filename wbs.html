What is a Work Breakdown Structure?

The WBS is a deliverable-oriented hierarchical decomposition of the work to be executed by the project team to accomplish the project objectives and create the required deliverables.

📚 Key Principle (7th Edition)

"The WBS represents 100% of the work defined by the project scope. Each level of decomposition represents increasingly detailed definitions of project work."

The 100% Rule

The WBS must capture all project work:

  • ✅ The sum of work at the child level must equal 100% of work at the parent level
  • ✅ No work should exist outside the WBS (no "hidden" work)
  • ✅ No work should be duplicated (no overlap between elements)

The Decomposition Process

1

Identify Major Deliverables

Start with the project scope statement. Identify the major deliverables or phases.

2

Determine Decomposition Level

Continue breaking down until work packages are 8-80 hours (the "8/80 rule").

3

Verify 100% Coverage

Ensure all scope is represented and no work is duplicated.

4

Create WBS Dictionary

Document detailed information for each work package.

💡 The 8/80 Rule

Work packages should be sized between 8 hours (1 day) and 80 hours (2 weeks). This provides enough detail for accurate estimation while keeping management overhead reasonable.

WBS Dictionary

The WBS Dictionary provides detailed information about each work package. It serves as the foundation for scheduling, estimating, and monitoring.

Sample WBS Dictionary Entries

2.2 Roof Reinforcement
Description: Structural upgrades to support solar panel load including beam reinforcement and load distribution analysis
Responsible: Structural Engineer (Lead: James Morrison, PE)
Duration: 4 weeks
Cost: R3,240,000
Acceptance Criteria: Structural engineer sign-off, passes city inspection, load test documentation
Dependencies: Permit approval (2.1), Site survey completion
Resources: Structural crew (4), Crane operator, Steel beams, Concrete
Milestones: Week 2: Beam installation complete, Week 4: Final inspection
4.2 Panel Installation
Description: Mount and connect all 800 solar panels to mounting system and electrical infrastructure
Responsible: Installation Crew (Lead: Maria Santos)
Duration: 6 weeks
Cost: R4,320,000
Acceptance Criteria: All panels securely mounted, electrical connections torqued to spec, visual inspection passed
Dependencies: Mounting system complete (4.1), Panels delivered (3.1)
Resources: Installation crew (8), Lift equipment, Torque wrenches
Milestones: Week 2: 25% complete, Week 4: 50% complete, Week 6: 100% complete

WBS Best Practices

✅ DO

  • Use nouns for deliverables (not verbs)
  • Apply the 100% rule consistently
  • Keep work packages 8-80 hours
  • Involve the team in decomposition
  • Base on deliverables, not phases
  • Use consistent numbering
  • Create WBS dictionary entries

❌ DON'T

  • Include project phases as elements
  • Make work packages too large
  • Forget the WBS dictionary
  • Include "project management" as catch-all
  • Duplicate work across branches
  • Decompose everything to same level
  • Create WBS in isolation

Common WBS Mistakes

Mistake: Verb-Based Elements

Wrong: "Plan Project" "Execute Project" "Monitor Project"

Right: "Project Plan" "Installed System" "Performance Reports"

Mistake: Forgetting 100% Rule

Parent budget: R1,000,000. Sum of children: R850,000. Missing R150,000 of work!
